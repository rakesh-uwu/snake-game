# Multiplayer Snake Game

A web-based multiplayer Snake game for 2-4 players. Compete to collect the most eggs and survive the longest!

## Game Description

This is a modern twist on the classic Snake game, designed for 2-4 players. Each player controls their own snake on the same board. The goal is to collect as many eggs as possible while avoiding collisions with walls, yourself, or other players. The player with the highest score at the end wins!

## How to Play

- **Players:** 2-4 (each with their own controls)
- **Objective:** Collect eggs to score points and survive longer than your opponents.
- **Controls:**
  - Each player uses the WASD keys to control their snake (W = up, A = left, S = down, D = right).
  - Avoid running into walls, yourself, or other snakes.
  - The game ends when only one snake remains or a set time/score is reached.

## Controls

- **All Players:** WASD (W = up, A = left, S = down, D = right)

## How to Run the Game

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm start
   ```
   The game will open at [http://localhost:3000](http://localhost:3000).

3. **Build for production:**
   ```bash
   npm run build
   ```

## Features
- Real-time multiplayer gameplay
- 2-4 player support
- Competitive egg collection
